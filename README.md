# zapret для League of Legends (EUNE, EUW)

Рабочая копия [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) версии 1.9.9a с профилем для League of Legends. Профиль сделан для EUNE, на EUW тоже работает: используется та же инфраструктура Riot.

Остальные профили дистрибутива не менялись. Для Discord и YouTube можно устанавливать их тем же способом.

Основа распространяется по лицензии MIT, текст в [LICENSE.txt](LICENSE.txt).

**С 25.10.2026 одной службы недостаточно: нужны ещё пины в файл `hosts` - см. [раздел про hosts](#пины-в-файл-hosts).**

## Запуск только через службу

Для League of Legends профиль нужно запускать службой Windows, а не файлом `general(ALT11)lol.bat`. Vanguard стартует при загрузке Windows раньше, чем вы успеете запустить bat вручную, и игра выдаёт одну из VAN-ошибок. Служба с автозапуском поднимает обход до старта Vanguard, поэтому ошибка не появляется.

Файл `general(ALT11)lol.bat` в этой схеме не запускается. `service.bat` читает из него параметры winws и передаёт их службе.

## Установка службы

Нужна Windows 10 или 11 и права администратора.

1. Скопировать папку в постоянный путь без кириллицы, например `D:\zapret`. Служба запоминает этот путь. Если папку потом перенести, службу нужно переустановить.
2. Запустить `service.bat` двойным кликом. Скрипт сам запросит права администратора, в окне UAC нажать `Да`.
3. В меню, оно на английском, выбрать `1. Install Service` и нажать Enter.
4. Скрипт покажет пронумерованный список профилей. Найти `general(ALT11)lol.bat`, в текущем наборе это пункт 20, ввести `20` и нажать Enter.
5. Скрипт создаст службу `zapret` с автозапуском, запустит её и покажет строку `Final args`. Нажать любую клавишу.
6. Выбрать `3. Check Status`. В выводе должно быть `zapret service is RUNNING` и `Bypass (winws.exe) is RUNNING`.
7. Выбрать `0. Exit` и закрыть окно.

После перезагрузки служба запустится сама, до входа в систему. К моменту старта Vanguard обход уже работает.

Если профиль уже был запущен вручную, перед установкой закройте `winws.exe` через диспетчер задач или перезагрузитесь. Иначе служба может не занять порты.

## Пины в файл hosts

С 25 октября 2026 провайдеры в РФ блокируют отдельные IP-адреса Cloudflare, на которых работают авторизация, конфиг и патч-сервис Riot Client. Клиент выбирает адрес из пула случайно: часть запусков проходит, часть заканчивается "Нет соединения с интернетом" или висящей инициализацией. Пины в `hosts` фиксируют проверенные рабочие адреса.

Откройте `C:\Windows\System32\drivers\etc\hosts` от имени администратора (например, Блокнотом, запущенным от админа) и добавьте в конец:

```text
104.16.206.131 auth.riotgames.com
104.16.206.131 account.riotgames.com
104.18.157.37 clientconfig.rpg.riotgames.com
104.16.56.21 data.riotgames.com
104.16.56.21 entitlements.auth.riotgames.com
104.16.206.131 sieve.services.riotcdn.net
```

После сохранения - `ipconfig /flushdns` в cmd и полный перезапуск Riot Client (трей -> Выход). Перед правкой сделайте копию файла.

Зачем каждый хост:

- `auth.riotgames.com`, `account.riotgames.com` - вход и страница аккаунта;
- `clientconfig.rpg.riotgames.com` - конфиг клиента; без него клиент висит на инициализации;
- `data.riotgames.com`, `entitlements.auth.riotgames.com` - токены доступа и телеметрия;
- `sieve.services.riotcdn.net` - патч-сервис: отдаёт версию сборки LoL.

Если не запинить `sieve`, League-клиент запускается, ~2 минуты повторяет `SSL failure error 35` и закрывается сам - со стороны это выглядит как "кнопка Play не работает". Если не запинить `clientconfig`, клиент открывается через 2–5 минут ретраев или не открывается вовсе.

Правила:

- Одна строка на хост: при двух записях Windows возьмёт только первую, дубли бесполезны.
- Блэкхолы меняются волнами: IP, которые работают сегодня, завтра могут лечь и наоборот. Умер пин (запрос виснет) - замените строку на живой адрес Cloudflare, а не добавляйте вторую.
- Быстрая проверка из cmd: `curl -sS -o NUL -w "%{http_code}\n" https://auth.riotgames.com`. Любой HTTP-код (404, 405, 307) - узел отвечает; `000` - мёртвый.
- `hosts` работает независимо от версии zapret и профиля: это системный файл, служба на него не влияет.

## Смена профиля и удаление

- Сменить профиль: снова `1. Install Service` и указать номер другого профиля. Скрипт пересоздаст службу.
- Если пересоздание не сработало: сначала `2. Remove Services`, затем `1. Install Service`.
- Удалить службу: `2. Remove Services`.
- Проверить из консоли: `sc query zapret` в cmd от администратора.

## Что добавлено

### general(ALT11)lol.bat

Профиль скопирован с `general (ALT11).bat` и изменён:

- добавлен фильтр TLS-трафика Riot: порт 443, домены из `lists/list-lol.txt`, `--dpi-desync=fake` с `badseq`. Стоит первым среди TCP-фильтров и не наследует исключения: домены Riot есть в стоковом `list-exclude.txt`, и без отдельного правила они не обходились бы;
- в `--wf-tcp` добавлены порты 2091, 2099, 5223, 8393-8400, для них - правило `--dpi-desync=syndata` по `lists/ipset-lol.txt`;
- в `--wf-udp` добавлен диапазон 5000-5500 (игровой трафик LoL) с fake-пакетами по `lists/ipset-lol.txt`.

Этот файл используется только как шаблон для установки службы. Отдельно его запускать не нужно.

### lists/list-lol.txt

Домены Riot для отдельного фильтра на 443: `riotgames.com`, `leagueoflegends.com`, `riotcdn.net`, `pvp.net`, `riot-client.com`, `rgpub.io`.

### lists/ipset-lol.txt

364 подсети Riot Games и игровых серверов (AWS, Global Accelerator). Файл используется только профилем lol.

### Списки

- `list-exclude-user.txt`: заглушка из шаблона и `Deepseek.com`. Домены Riot удалены: они обходятся отдельным фильтром, а не исключением;
- `ipset-exclude-user.txt`: только заглушка `203.0.113.113/32`. Диапазоны Riot удалены по той же причине;
- `list-general-user.txt`: `riotcdn.net`;
- `list-general.txt`: расширенный, включая DoH-домены (`^dns.google`, `^dns.quad9.net`, `^dns.nextdns.io` и др.) в начале файла;
- `list-google.txt`: добавлен `stitch.withgoogle.com`;
- `list-exclude.txt`: стоковый.

## Примечания

- Обновить `ipset-all.txt` можно через `7. Update IPSet List`. После обновления перезапустите службу через `2. Remove Services`, затем `1. Install Service`, иначе winws продолжит работать со старым списком. Пользовательские файлы `*-user.txt` при обновлении не меняются.
- Антивирус может ругаться на WinDivert. Добавьте папку в исключения, драйвер нужен для перехвата трафика.
- В `list-general.txt` есть повторы. Они оставлены намеренно, чтобы файл совпадал с рабочим состоянием.
- В папке сохранён результат тестов от 01.06.2026. Лучшим профилем тогда оказался `general (ALT11).bat`.
- Файлы хранятся байт-в-байт: CRLF и кодировки не меняются при клонировании.
